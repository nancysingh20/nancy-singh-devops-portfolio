System Health Monitor

A Linux system health monitoring project automated through Jenkins CI/CD.

Project Overview

The project collects system information and monitors CPU, memory and disk utilization against defined thresholds.

Jenkins automatically executes the Bash monitoring script, generates a health report and archives the report as a build artifact.

Technologies Used

Linux Bash Git GitHub Jenkins CI/CD Docker

Architecture

GitHub | v Jenkins | v Checkout Source Code | v Bash Health Monitor | +---- CPU Check | +---- Memory Check | +---- Disk Check | v Overall System Health | +---- HEALTHY | +---- CRITICAL | v health_report.txt | v Jenkins Artifact

Jenkins Pipeline

Monitoring

The Bash script checks CPU, memory and disk utilization and reports whether each resource is within the configured threshold.

The project also captures hostname, current user, current date, CPU statistics and system uptime.

Example Healthy Result

CPU Usage: 1% HEALTHY: CPU usage is below 80%. Memory Usage: 37% HEALTHY: Memory usage is below 80%. Root Disk Usage: 1% HEALTHY: Disk usage is below 80%. OVERALL SYSTEM HEALTH: HEALTHY

CI/CD Implementation

The Jenkins pipeline performs source-code checkout, executes the monitoring script, generates the health report and archives the report as a Jenkins artifact.

Failure Handling

If CPU, memory or disk utilization exceeds the configured threshold, the monitoring script marks the overall system health as CRITICAL and returns a non-zero exit code.

Jenkins then marks the pipeline as FAILED.
